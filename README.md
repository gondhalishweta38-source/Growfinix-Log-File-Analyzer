# Growfinix Log File Analyzer

## Project Description

This project is a Java-based Log File Analyzer developed as part of the Growfinix Java Internship Program.

The application reads a log file, extracts error codes using Regular Expressions (Regex), analyzes log data using the Java Streams API, and generates a summary report.

## Features

* Read log files using Java NIO.2
* Extract error codes using Regex
* Count occurrences of each error code
* Generate error summary reports
* Find the most frequent error code
* Display total log entries and error entries

## Technologies Used

* Java 21
* Java NIO.2
* Java Streams API
* Regular Expressions (Regex)
* Collections Framework
